# Agent release builds

Create the supported agent artifacts from the repository root:

```powershell
.\scripts\build-agent-release.ps1 -Version 0.1.0
```

The script writes statically linked binaries to `dist/agent` for Linux
(`amd64`, `arm64`), macOS (`amd64`, `arm64`), and Windows (`amd64`). The
requested version is embedded in every binary and can be checked with:

```powershell
.\dist\agent\tunnel-agent_0.1.0_windows_amd64.exe version
```

Use a release version containing only letters, digits, `.`, `_`, `+`, or `-`.
Run `go test ./...` from `agent` before publishing the files, and publish each
binary together with a checksum generated by the release system.

For an iterative local build, limit the script to one or more targets, for
example `-Target windows/amd64`.

To connect the Windows executable to either the local Compose stack or a
deployed gateway, follow [windows-agent.md](windows-agent.md).
